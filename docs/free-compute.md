# Free workers in the supervised build

One existing Codex session supervised this experiment. Workers used explicitly selected OpenRouter free routes, configured Google free-project routes, Groq free-plan and Cohere trial routes, and the already resident local Gufo model. No additional Codex or Claude subscription worker, paid fallback, purchase or billing change was used. The existing controller still consumes its own subscription allowance.

The [sanitized run summary](../evidence/2026-11-15-compute/summary.json) records 77 bounded task attempts (76 generation-request attempts and one catalogue-admission refusal) across five provider families: 23 catalogue-listed provider-model pairs, plus one mistakenly attempted absent Groq selector. Google native and OpenAI-compatible adapters are one model pair. There were 53 returned final answers; seven corrected scaffolds/helpers were integrated and thirteen bounded outputs were independently checked. Returned answers, useful review findings and accepted code are separate outcomes.

All fourteen advertised OpenRouter free selectors were attempted. Eleven returned useful bounded outputs after task sizing; two Gemma routes remained throttled and Inkling was region-refused. Every returned OpenRouter cost field was zero. Several larger code/review tasks exhausted their output budget in reasoning without a final answer. A smaller exact extraction task then worked on those routes. That observation supports changing the task contract, not ranking a model globally from one failure.

Qwen 27B contributed floating-layout and native-editor scaffolds. Flash-Lite supplied bounded styling and bundling work. Gufo's repaired coordinate helper passed boundary checks; vision routes read selected fixture screenshots. The supervising agent corrected APIs and lifecycle ownership, exercised the resulting code and rejected an out-of-bounds visual action before sending input. A fast OSS 20B policy answer had a wrong truth-table case and was rejected. The final Qwen review alleged a framework lease leak that pinned source disproved.

The [three-role review](spec-review.md) separated native lifetime, numbered-claim falsity and documentation consistency. Review packets used bounded inline public source or public-source read tools, with no repository writes, commands, credentials or private chats. Later reviewers also emitted unsupported pseudo-tool calls or incorrect lifetime traces; those outputs were rejected against executable checks. No pseudo-command was executed. Source review did not substitute for the actual GPU, native-client, Zenbook or video checks.

The strong/medium/small labels in the summary are pre-run routing priors. Token and timing counters are reported as the providers supplied them; reasoning may overlap completion, and elapsed time includes queueing and tool rounds. These heterogeneous tasks are not a comparative model benchmark. The full catalogue, numerical remaining account allowances, raw API receipts and per-task reviewed dispositions stay private. Advertised models and multiple keys are not additive compute pools.

Known admission limits were retained without bypass: Google Flash timed out even on a small native-API request, Gemma returned 429, Inkling refused the region, and a stale Groq Llama selector was absent from the live catalogue. Unknown free entitlement on other providers was a hold. The controller now validates Groq selectors against its live catalogue and uses an absolute request deadline rather than only a socket timeout.
